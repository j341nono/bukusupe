### 決めたこと（2026-09-27、使う人の判断。詳しくは `docs/RELEASE.md`「決めたこと」）

1. 星座のメンバー：保存した時点で固定し、新しく合う星は「新星」として示す（段階 5。SPEC 9 章を先に直し、今の星座からの移行を作る）。
2. ブックマークの削除：しない。片付け候補を示し、Chrome のブックマーク マネージャーで開く（段階 7）。**規則 3 は変えない。**
3. 新しいタブ版：1.0 では出さない。需要があれば別の拡張機能として検討する。
4. ブックマークが多い人：すべてを対象にし、最近使ったものから先に計算する（段階 5）。
5. 英語対応：画面の文言と掲載文だけ（モデルは変えない）。
6. バックアップ：JSON の書き出し・読み込み。星座のメンバーは URL で持つ。同期は使わない。
7. 問題を報告する窓口：GitHub の Issues（https://github.com/j341nono/bukusupe/issues）とメール（`j341nono.dev [at] gmail.com`、2026-09-28 に受け取った。`src/config.ts`）。
8. WebGL が使えない環境：案内だけ。
9. モデルの重み：今のまま Hugging Face から取得する。段階 2 で**まず `host_permissions` を外せないか確かめる**（Web のデモは権限なしで
   取得できている。拡張機能の画面と Worker からも CORS で取れれば、インストール時の強い警告がなくなる）。外せなければ最小限のドメインに絞る。
10. フォルダの自動星座：利用者が選んだフォルダだけ。

### 新しく足した規則（`CLAUDE.md` / `AGENTS.md` の 9〜11）

- ページやブックマークから来た文字列（タイトル・URL など）を HTML として解釈させない（`innerHTML` などに入れない）。
- 利用者のデータを外部に送る処理、分析用のデータを集める処理を書かない。
- 配布物（ストア向けのビルド）に、測定用・確認用の仕組みを含めない（段階 2 で分ける。それまでは開発用の `dist/` に残っている）。
