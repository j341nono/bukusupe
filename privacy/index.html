ブクスペ プライバシーポリシー

最終更新：2026 年 9 月 28 日

ブクスペは、あなたのブックマークをブラウザの中だけで扱います。ブックマークの内容を外部に送ることはありません。 分析・広告・第三者への提供はしません。外部との通信は、初回に意味の計算に使うモデルのデータを Hugging Face から取得することだけです。

ブクスペについて

ブクスペ（Bookmark Space）は、Chrome のブックマークを星として、意味の近いものが近くに集まる宇宙の地図に並べ、検索で引き寄せたり、 選んだ星を結んで「星座」として残したり、星の間を飛んだりできる Chrome 拡張機能です。このポリシーは、Chrome 拡張機能と、 GitHub Pages で公開している Web のデモに適用されます。

扱うデータ

  • ブックマーク：タイトル、URL、フォルダ名、追加日時、最終利用日時。Chrome のブックマークの機能から読み取るだけで、 ブックマークを変更・削除することはありません。
  • 計算した結果：ブックマークの意味を表す数値（埋め込み）と、地図の上の配置。
  • 星座：あなたが付けた名前、星座に入れたブックマーク、検索から作った場合はその検索語と、検索語の意味を表す数値、見送った「新星」、作成日時。
  • 画面の状態：ページを開いた後にブラウザの「戻る」で続きから再開するための、地図の位置・検索語・飛行中の宇宙船の位置など（一時的なもの）。
  • 設定：サンプルの宇宙を使うかどうか、案内を一度表示したかどうか。

氏名・メールアドレスなどの個人を特定する情報や、閲覧履歴は扱いません。アカウントの登録もありません。

処理と保存の場所

上のデータは、すべてあなたのブラウザの中で処理し、ブラウザの中（拡張機能の保存領域：IndexedDB、Cache Storage、localStorage、sessionStorage）に保存します。 意味の計算もブラウザの中で行います。開発者のサーバーはなく、これらのデータを外部に送ることはありません。

外部との通信

  • モデルのデータの取得：初回の説明で「始める」を押した後（と、ブラウザのキャッシュが消えたとき）に、意味の計算に使うモデル（Xenova/multilingual-e5-small）の データを Hugging Face（huggingface.co と、その配信用の *.hf.co）からダウンロードします。取得したデータはブラウザの中に保存し、 次からはそれを使います。モデルの版を固定し、取得したファイルとキャッシュのファイルを、記録済みの SHA-256 と照合してから使います。
  • この通信は読み込み（GET）だけで、ブックマークの内容や星座は含みません。一般的なウェブの通信と同じく、通信先には、あなたの IP アドレス、 ブラウザの種類（User-Agent）、言語の設定、拡張機能の識別子（Origin）などが届きます。これらの扱いは Hugging Face のプライバシーポリシーに従います。
  • プログラム（スクリプト・WebAssembly）はすべて拡張機能に同梱しており、外部から読み込みません。
  • ブックマークのページは、あなたが星を選んで開いたときだけ、ふつうのページの移動として開きます。

サイトのアイコン

飛行モードで表示するサイトのアイコンは、Chrome がすでに端末に持っているもの（favicon の権限）を表示します。アイコンを取りに外部へ通信することはありません。

しないこと

  • 利用状況の計測・分析、エラーの自動送信をしません。
  • 広告を表示しません。
  • データを第三者に提供・販売しません。

ブクスペがブックマークなど Chrome の機能から受け取る情報の使い方は、Chrome ウェブストアの利用者のデータに関するポリシー （限定的な使用の要件を含む）に従います。The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

データの消し方

  • 拡張機能を Chrome から削除すると、ブクスペが保存したデータ（計算した結果、配置、星座、モデルのデータ、画面の状態、設定）はすべて消えます。
  • 星座は、画面下の星座の名前の横の「…」から「削除」で、一つずつ消せます。
  • ブックマークそのものは Chrome のデータで、ブクスペが消すことはありません。

Web のデモ

GitHub Pages で公開している Web のデモは、同梱したサンプルのブックマークだけを使い、あなたのブックマークは読みません。 モデルのデータの取得は拡張機能と同じです。ページの配信には GitHub が関わり、アクセスの記録は GitHub のプライバシーに関する声明に従います。

このポリシーの変更

内容を変えるときは、このページを更新し、最終更新日を改めます。外部に送るデータが増えるなど大きな変更をする場合は、 その変更を含む版を公開する前に、このページと更新の説明でお知らせします。

Bukusupe Privacy Policy

Last updated: September 28, 2026

Bukusupe handles your bookmarks only inside your browser. It never sends the contents of your bookmarks anywhere. There is no analytics, no advertising, and no sharing with third parties. The only network access is a one-time download of the language model data from Hugging Face.

About Bukusupe

Bukusupe (Bookmark Space) is a Chrome extension that shows your Chrome bookmarks as stars on a map of a universe, where bookmarks with similar meanings gather together. You can pull stars in with search, connect stars you pick into saved "constellations", and fly between them. This policy covers the Chrome extension and the web demo published on GitHub Pages.

Data we handle

  • Bookmarks: title, URL, folder names, date added, and date last used. Bukusupe only reads them through Chrome's bookmarks feature. It never changes or deletes your bookmarks.
  • Computed results: numbers that represent the meaning of each bookmark (embeddings) and positions on the map.
  • Constellations: the name you give, the bookmarks in it, and, if you made it from a search, the search words and the numbers that represent their meaning; "new stars" you chose to skip; the creation time.
  • Screen state: temporary data (map position, search words, the spaceship's position) used to resume where you left off when you come back with the browser's Back button.
  • Settings: whether to use the sample universe, and whether a hint has been shown.

Bukusupe does not handle personally identifying information such as your name or email address, nor your browsing history. No account is needed.

Where data is processed and stored

All of the data above is processed inside your browser and stored in the extension's storage in your browser (IndexedDB, Cache Storage, localStorage, sessionStorage). The meaning is also computed inside your browser. There is no developer server, and this data is never sent out.

Network access

  • Model download: after you press “Start” on the first-run explanation (and again if the browser cache is cleared), Bukusupe downloads the data of the language model (Xenova/multilingual-e5-small) from Hugging Face (huggingface.co and its delivery hosts *.hf.co). The data is kept in your browser and reused afterwards. The model revision is pinned, and every downloaded or cached file is checked against its recorded SHA-256 hash before use.
  • These requests only read data (GET) and never include your bookmarks or constellations. As with any web request, the server receives your IP address, browser type (User-Agent), language settings, and the extension's identifier (Origin). Hugging Face handles them under the Hugging Face Privacy Policy.
  • All program code (scripts and WebAssembly) is bundled in the extension; nothing is loaded from outside.
  • A bookmarked page is opened only when you choose a star, as a normal page navigation.

Site icons

The site icons shown in flight mode are the ones Chrome already has on your device (the favicon permission). Bukusupe does not go online to fetch icons.

What we do not do

  • No usage tracking or analytics, and no automatic error reports.
  • No advertising.
  • No sharing or selling of data to third parties.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

How to delete your data

  • Removing the extension from Chrome deletes everything Bukusupe stored (computed results, positions, constellations, model data, screen state, and settings).
  • You can delete a constellation one at a time from the "…" menu next to its name at the bottom of the screen.
  • Your bookmarks themselves belong to Chrome; Bukusupe never deletes them.

Web demo

The web demo on GitHub Pages uses only the bundled sample bookmarks and never reads your bookmarks. It downloads the model data in the same way as the extension. GitHub serves the pages, and its access records are governed by the GitHub General Privacy Statement.

Changes to this policy

When this policy changes, this page is updated along with the "Last updated" date. For significant changes, such as sending more data out, we will announce them on this page and in the release notes before publishing the version that includes the change.
